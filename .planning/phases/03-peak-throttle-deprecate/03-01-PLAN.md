<objective>
Soft-deprecate the peak-throttle feature by removing every UI surface that references it from the Electron renderer and the main-process IPC bridge, while leaving the pure helper module `src/shared/peak-throttle.js` and its vitest spec `tests/peak-throttle.test.js` completely untouched. After this plan: the peak-throttle promo card no longer renders in the widget, the tray icon never shows the red "throttled" stripe or the "(peak throttle)" tooltip suffix, the renderer no longer asks main for throttle status, and the `get-peak-throttle-status` IPC channel + the `getPeakThrottleStatus` preload bridge no longer exist. The shared module remains a private helper, ready to be re-wired if a different rate-limit-window indicator is later requested.

Purpose: Anthropic's weekday peak-throttle window is no longer in effect. Keeping the UI live shows stale information. Removing only the UI (not the helper) preserves optionality without dragging dead code through every surface, matching the "Peak-throttle handling: soft-deprecate" decision in `PROJECT.md`.

Output: edits to `src/renderer/index.html` (delete the `promoBanner` card markup), `src/renderer/app.js` (delete the elements cache entries, the init hooks, the loader/renderer functions, and the tray-frame throttle path), `preload.js` (delete the `getPeakThrottleStatus` bridge), `main.js` (delete the `get-peak-throttle-status` IPC handler and the now-unused `peakThrottleShared` require). No edits to `src/shared/peak-throttle.js`. No edits to `tests/peak-throttle.test.js`. No new files. No new dependencies. No protected files touched.
</objective>
