<objective>
Add a "Check for updates" action to the settings drawer so the user can trigger the existing GitHub-releases version check on demand and see the result inline (up-to-date / new version available / check failed) plus the timestamp of the last successful check. Today the renderer only fires `checkForUpdate()` automatically: once on startup with a 2-second delay (`src/renderer/app.js:215`), once every 24 hours (`src/renderer/app.js:217`), and once after a session timer rolls over (`src/renderer/app.js:1275`). When `result.hasUpdate` is true the renderer shows the orange `#updateBanner` (`src/renderer/index.html:65-68`) and populates the inline `#settingsUpdateLink` in the settings footer (`src/renderer/index.html:677`). When `result.hasUpdate` is false there is no UI feedback whatsoever — the user has no way to know "the app checked and you're up to date". After this plan: a button in the settings drawer triggers the same `window.electronAPI.checkForUpdate()` call, the button enters a pending state during the request, and a dedicated status line below the button reports the outcome ("Up to date — last checked 14:32", "Version 1.15.0 available — click to download", or "Check failed — try again"). The existing automatic checks, the orange banner, the footer `#settingsUpdateLink`, and the IPC handler in `main.js` are all untouched — this plan only adds a new on-demand UI surface that reuses the existing pipeline.

Purpose: The roadmap (`.planning/ROADMAP.md` Phase 6) calls this out as the manual-update-check feature for the v1.15 polish milestone. Today the user must wait up to 24 hours after launch (or restart the app) to retrigger the version check, and even then the only visible feedback is the orange banner — which only appears when an update exists. There is no way to confirm "I'm on the latest". This plan closes that gap with a single button + status line in the existing settings drawer (Phase 5 just cleared the drawer's structural baseline; the `.settings-overlay` already has clean room below the title-bar). The work is renderer-side only: the `check-for-update` IPC handler at `main.js:768-814` already does exactly the right thing (scans the GitHub releases list, picks the highest semver, returns `{ hasUpdate, version }`), and the `preload.js` bridge (`checkForUpdate: () => ipcRenderer.invoke('check-for-update')` at line 68) is already exposed. No new IPC, no new preload bridge, no main-process change.

Surgical edit, one block. Replace the current handler body:

```js
ipcMain.handle('check-for-update', () => {
  return new Promise((resolve) => {
    const options = {
      hostname: 'api.github.com',
      path: `/repos/${GITHUB_OWNER}/${GITHUB_REPO}/releases?per_page=20`,
      method: 'GET',
      headers: {
        'User-Agent': 'claude-usage-widget',
        'Accept': 'application/vnd.github+json'
      },
      timeout: 5000
    };

    const req = https.request(options, (res) => {
      let body = '';
      res.on('data', (chunk) => { body += chunk; });
      res.on('end', () => {
        try {
          const data = JSON.parse(body);
          if (!Array.isArray(data)) {
            resolve({ hasUpdate: false, version: null });
            return;
          }
          const current = app.getVersion();
          let best = null;
          for (const rel of data) {
            if (rel.draft) continue;
            const tag = (rel.tag_name || '').replace(/^v/, '');
            if (!tag) continue;
            if (!best || compareVersions(tag, best) > 0) best = tag;
          }
          if (best && isNewerVersion(best, current)) {
            resolve({ hasUpdate: true, version: best });
          } else {
            resolve({ hasUpdate: false, version: null });
          }
        } catch {
          resolve({ hasUpdate: false, version: null });
        }
      });
    });

    req.on('error', () => resolve({ hasUpdate: false, version: null }));
    req.on('timeout', () => { req.destroy(); resolve({ hasUpdate: false, version: null }); });
    req.end();
  });
});
```

      headers: {
        'User-Agent': 'claude-usage-widget',
        'Accept': 'application/vnd.github+json'
      },
      timeout: 5000
    };

    const req = https.request(options, (res) => {
      let body = '';
      res.on('data', (chunk) => { body += chunk; });
      res.on('end', () => {
        try {
          const data = JSON.parse(body);
          if (!Array.isArray(data)) {
            resolve({ ok: false, hasUpdate: false, version: null });
            return;
          }
          const current = app.getVersion();
          let best = null;
          for (const rel of data) {
            if (rel.draft) continue;
            const tag = (rel.tag_name || '').replace(/^v/, '');
            if (!tag) continue;
            if (!best || compareVersions(tag, best) > 0) best = tag;
          }
          if (best && isNewerVersion(best, current)) {
            resolve({ ok: true, hasUpdate: true, version: best });
          } else {
            resolve({ ok: true, hasUpdate: false, version: null });
          }
        } catch {
          resolve({ ok: false, hasUpdate: false, version: null });
        }
      });
    });

    req.on('error', () => resolve({ ok: false, hasUpdate: false, version: null }));
    req.on('timeout', () => { req.destroy(); resolve({ ok: false, hasUpdate: false, version: null }); });
    req.end();
  });
});
